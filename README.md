---

## 📝 Descrição do Sistema

Este projeto tem como objetivo desenvolver um sistema para gerenciamento de agendamentos, permitindo o cadastro de usuários, criação de horários disponíveis e marcação de atendimentos.  

O sistema busca facilitar o controle de agendas, reduzir conflitos de horários e oferecer uma experiência simples tanto para administradores quanto para usuários finais.
